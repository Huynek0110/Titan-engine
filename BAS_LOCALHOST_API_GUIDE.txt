TITAN ENGINE - BAS LOCALHOST API GUIDE (MERGE UPDATE)

============================================================
0) QUICK START
============================================================
- Open app, click HOST button -> HOST: ON
- Base URL: http://localhost:5555
- Recommended BAS flow:
  1) POST /api/queue/add
  2) POST /api/queue/start
  3) GET /api/render/status?jobId=...

Completion rule in BAS:
- done == true
- then check jobSuccess == true

============================================================
1) UI MERGE VIDEOS / IMAGES (MANUAL APP USAGE)
============================================================
If you want many sources -> 1 output file in UI:
1) Select multiple videos/images
2) Tick: "Merge Videos Into One Output (Concat)"
3) (Optional) Select multiple audio files + tick "Merge Audio Tracks Into One Output (Concat)"
4) (Optional) Select a Template in FX Studio (CapCut style preset)
5) Set FX/Color/Upscale/etc as normal
6) Click ADD TO QUEUE

Result:
- Only 1 queue item is created
- Render output is 1 merged video

============================================================
2) API ENDPOINTS
============================================================
[A] POST /api/queue/add
- Add job to queue only (no render yet)

[B] POST /api/queue/start
- Start all pending queue jobs

[C] GET /api/render/status?jobId=DE64988F
- Poll current job state
- Supports jobId string or queueId number

[D] POST /api/render
- Add + render immediately in background (async)

[E] POST /api/render/async
- Same as /api/render async behavior

[F] POST /api/render/wait
- Blocking mode (wait until done)

============================================================
3) MERGE VIDEOS + MERGE AUDIO VIA API
============================================================
Use these fields:
- inputFiles: array of video paths
- inputFiles can also include image paths (.png/.jpg/.jpeg)
- mergeVideos: true
- audioFiles: array of audio paths (optional)
- mergeAudio: true (optional, auto true when audioFiles > 1)
- outputVideo: final output path
- templateName: optional preset name

Example (merge 2 videos -> 1 output):
POST http://localhost:5555/api/queue/add
{
  "inputFiles": [
    "C:\\Users\\lemin\\Desktop\\clip1.mp4",
    "C:\\Users\\lemin\\Desktop\\clip2.mp4"
  ],
  "audioFiles": [
    "C:\\Users\\lemin\\Desktop\\music1.mp3",
    "C:\\Users\\lemin\\Desktop\\music2.mp3"
  ],
  "mergeVideos": true,
  "mergeAudio": true,
  "templateName": "Smooth Zoom In",
  "outputVideo": "C:\\Users\\lemin\\Desktop\\output\\merged_final.mp4",
  "colorGrading": "Warm",
  "fxEffect": "None"
}

Important:
- If inputFiles has more than 1 item, app will auto use merge workflow.
- If audioFiles has more than 1 item, app will auto merge audio tracks.
- Queue will create 1 job for that merged output.

4AA) TEXT OVERLAY (textOverlay + textOverlayAnimation)
============================================================
Fields:
- textOverlay: the text to burn in. Supports \n for line breaks.
- textOverlayPosition: Center, Top, Bottom, Top Left, Top Right, Bottom Left, Bottom Right, Custom
- textOverlayStyle: font family, list below
- textOverlayFontSize: 16 - 150 (default 32)
- textOverlayColor: color name or hex, e.g. "white", "#FF66CC"
- textOverlayXPercent / textOverlayYPercent: 0 - 100, used when position = Custom
- textAlign: Auto, Left, Center, Right (optional)
- textOverlayAnimation: the effect, list below
- textOverlayEffectDuration: total seconds the effect plays (default 5.0, range 1 - 60)
- enableTextGlow / textGlowColor: legacy drawtext neon aura (see note)
- addQuotes: wrap text in artistic quotes
- disableTextScroll: legacy mode only, freezes the upward scroll

textOverlayAnimation canonical values:
- Drawtext cu (Typewriter + Truot len + Neon Glow)   <- DEFAULT, legacy behaviour
- Mac dinh (Hien tinh)
- Spotify Scroll (Chu chay len)
- Pop & Bounce (Nay manh me)
- Smooth Drift (Troi lo lung)
- Glow Pulse (Toa sang nhu hoi tho)
- Karaoke Fade (Tu tu hien ro chu)
- Typewriter (Go tung chu)
- Blur Reveal (Mo ao hien dan)

Accepted aliases (case-insensitive, matched on keywords):
- drawtext / legacy / typewriter cu / cu -> legacy drawtext mode
- static / mac dinh / hien tinh -> static
- spotify / scroll / karaoke scroll -> Spotify Scroll
- pop / bounce / pop bounce -> Pop & Bounce
- drift / smooth drift / troi -> Smooth Drift
- glow / glow pulse / pulse / breathing -> Glow Pulse
- karaoke / word / fade -> Karaoke Fade
- typewriter / type / go chu -> Typewriter
- blur / blur reveal / mo ao -> Blur Reveal

textOverlayStyle canonical values:
- Aesthetic Lyric (Georgia / Times Italic)
- Modern Sans (Segoe UI Italic)
- Classic Serif (Times New Roman Italic)
- Clean Sans (Arial Italic)
- Thu Phap Nghe Thuat (Calligraphy)

Notes:
- Omitting textOverlayAnimation keeps the legacy drawtext mode, so old BAS
  scripts behave exactly as before.
- textOverlayEffectDuration is TOTAL time for the whole effect. Each line of the
  text gets 1/N of that window (N = number of lines). After the effect finishes
  the text stays on screen until the end of the video.
- Long text automatically degrades to a cheaper effect so the FFmpeg command
  line stays within the Windows 32767 character limit:
  Blur Reveal over 40 chars -> Typewriter,
  Typewriter over 60 chars -> per-word reveal,
  Karaoke over 45 words -> per-line reveal.
  The app logs a [FILTER-TEXT-ANIM-WARN] line when this happens.
- enableTextGlow / textGlowColor only apply to the legacy drawtext mode. The
  animation modes render without the neon aura; Glow Pulse has its own built-in
  breathing aura.
- Text is NOT auto-wrapped. Very long single lines can run off the frame edge.

Example:
POST http://localhost:5555/api/queue/add
{
  "inputFile": "C:\\Users\\lemin\\Desktop\\input.mp4",
  "outputVideo": "C:\\Users\\lemin\\Desktop\\output\\text_anim.mp4",
  "textOverlay": "Dong mot\nDong hai\nDong ba",
  "textOverlayPosition": "Bottom Center",
  "textOverlayAnimation": "Spotify Scroll",
  "textOverlayEffectDuration": 6.0,
  "textOverlayFontSize": 40
}
Then POST /api/queue/start and poll /api/render/status.

============================================================
4B2) CAPTION SYNC (enableCaptionSync) - AI WHISPER
============================================================
Independent from textOverlay. This one LISTENS to the audio with Whisper AI and
generates the subtitles automatically, so textOverlay must be omitted.

Fields:
- enableCaptionSync: true to run the Whisper pre-pass
- audioFile: REQUIRED. Captions are generated from this audio track only.
- captionSyncLanguage: Tu dong (Auto Detect), Tiep Viet, English, Nhat (Japanese),
  Han (Korean), Trung (Chinese)
- captionSyncModelSize: Small (466MB), Medium (1.5GB), Large V3 Turbo (1.6GB)
- captionSyncAnimation: Mac dinh, Spotify Scroll, Pop & Bounce, Smooth Drift,
  Glow Pulse, Karaoke Fade, Typewriter, Blur Reveal
- captionSyncFontFamily: same list as textOverlayStyle
- captionSyncPosition: Bottom Center, Top Center, Center, Custom (X% Y%)
- captionSyncFontSize: 16 - 72 (default 28)
- captionSyncColor: color name or hex (default white)
- captionSyncXPercent / captionSyncYPercent: 0 - 100, used when position = Custom

Notes:
- Requires whisper-cli.exe and the model in Assets\Whisper. The model is
  downloaded automatically on first use (Medium is about 1.5GB).
- Requires an ffmpeg audio extract pre-pass, so jobs take noticeably longer.
- Aliases accepted: captionSync / whisper / caption for the boolean,
  captionAnimation / whisperAnimation, captionFont / whisperFont,
  captionPosition / captionStyle, captionX / captionY, captionColor.

4C) AUDIO 1 VOICE FX (audio1Effect)
============================================================
Applies a built-in FFmpeg audio filter chain to the source video's own audio
track (Audio 1) only. External audio tracks (audioFile / Audio 2) are not
affected.

Field:
- audio1Effect: one of the presets below (empty string or "None" disables it)
- audio1EffectIntensity: effect strength 0-100 (default 100). 0 = no effect,
  100 = full effect. Scales echo decay, pitch-shift factor, telephone
  bandwidth, bitcrush bit depth, chorus/phaser strength, etc.

Canonical values:
- Không (Giữ nguyên) / empty        -> no FX (default)
- Echo (Vang nhiều tầng)            -> aecho 3 taps
- Church (Nhà thờ - aecho)          -> chained long aecho
- Robot/Glitch (Kim loại)           -> short metallic aecho + EQ
- Điện thoại (Bandpass)             -> highpass+lowpass band-limit
- Chipmunk (Tăng tone)              -> pitch up via asetrate+atempo
- Deep Voice (Giảm tone)            -> pitch down
- Chorus/Phát xung (Chorus)         -> chorus
- Phaser (Âm kim loại)              -> aphaser
- Bitcrush (Giọng rè kỹ thuật số)   -> acrusher
- Whisper (Thì thầm)                -> afftfilt randomized phase

Aliases are matched case-insensitively on keywords:
echo, church, robot, glitch, telephone, bandpass, chipmunk, deep,
chorus, phaser, bitcrush, whisper.

Example:
POST http://localhost:5555/api/queue/add
{
  "inputFile": "C:\\Users\\lemin\\Desktop\\voice.mp4",
  "outputVideo": "C:\\Users\\lemin\\Desktop\\output\\fx.mp4",
  "audio1Effect": "Church (Nhà thờ - aecho)"
}

Example:
POST http://localhost:5555/api/queue/add
{
  "inputFile": "C:\\Users\\lemin\\Desktop\\input.mp4",
  "audioFile": "C:\\Users\\lemin\\Desktop\\voice.mp3",

============================================================
8) TROUBLESHOOT
============================================================
- 503 Host mode is OFF:
  Turn HOST button ON.

- 429 Host is busy:
  Wait then retry.

- 404 jobId not found:
  Wrong jobId. Use jobId/statusUrl from add/render response.

- Merge fails:
  Ensure input files exist and are readable.
  Try same codec/container inputs for fastest concat.

- Fade not applied:
  Ensure request has:
  "enableFade": true
  "fadeInSeconds": number
  "fadeOutSeconds": number
  and check these values in API response.
