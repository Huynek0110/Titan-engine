============================================================
0) QUICK START
============================================================
- Open app, click HOST button -> HOST: ON
- Base URL: http://localhost:5555
- Recommended BAS flow:
  1) POST /api/queue/add
  2) POST /api/queue/start
  3) GET /api/render/status?jobId=...

Optional discovery call (any time, no body):
  GET /api/soundbar/presets  -> soundbar styles + colour palettes

Completion rule in BAS:
- done == true
- then check jobSuccess == true

Audio overlay rule:
- `audioFile` = Audio 1
- `audioFile2` = Audio 2
- `audioVolume` controls Audio 1 volume
- `audio2Volume` or `secondaryAudioVolume` controls Audio 2 volume
- If both `audioFile` and `audioFile2` exist, Titan mixes them together before render
- If only `audioFile2` exists, Titan uses it as the external audio track

============================================================
1) UI MERGE VIDEOS / IMAGES (MANUAL APP USAGE)
============================================================
If you want many sources -> 1 output file in UI:
1) Select multiple videos/images
2) Tick: "Merge Videos Into One Output (Concat)"
3) (Optional) Select multiple audio files + tick "Merge Audio Tracks Into One Output (Concat)"
4) (Optional) Select a Template in FX Studio (CapCut style preset)
5) Set FX/Color/Upscale/etc as normal
6) Click ADD TO QUEUE

Result:
- Only 1 queue item is created
- Render output is 1 merged video

============================================================
2) API ENDPOINTS
============================================================
[A] POST /api/queue/add
- Add job to queue only (no render yet)

[B] POST /api/queue/start
- Start all pending queue jobs

[C] GET /api/render/status?jobId=DE64988F
- Poll current job state
- Supports jobId string or queueId number

[D] POST /api/render
- Add + render immediately in background (async)

[E] POST /api/render/async
- Same as /api/render async behavior

[F] POST /api/render/wait
- Blocking mode (wait until done)

[G] GET /api/soundbar/presets
- Read-only discovery. Lists every soundbar style + colour palette (no body required)
- Use it to build a picker instead of hard-coding ids. See sections 9 and 10.

============================================================
3) MERGE VIDEOS + MERGE AUDIO VIA API
============================================================
Use these fields:
- inputFiles: array of video paths
- inputFiles can also include image paths (.png/.jpg/.jpeg)
- mergeVideos: true
- audioFiles: array of audio paths (optional)
- mergeAudio: true (optional, auto true when audioFiles > 1)
- outputVideo: final output path
- templateName: optional preset name

Example (merge 2 videos -> 1 output):
POST http://localhost:5555/api/queue/add
{
  "inputFiles": [
    "C:\\Users\\lemin\\Desktop\\clip1.mp4",
    "C:\\Users\\lemin\\Desktop\\clip2.mp4"
  ],
  "audioFiles": [
    "C:\\Users\\lemin\\Desktop\\music1.mp3",
    "C:\\Users\\lemin\\Desktop\\music2.mp3"
  ],
  "mergeVideos": true,
  "mergeAudio": true,
  "templateName": "Smooth Zoom In",
  "outputVideo": "C:\\Users\\lemin\\Desktop\\output\\merged_final.mp4",
  "colorGrading": "Warm",
  "fxEffect": "None"
}

Important:
- If inputFiles has more than 1 item, app will auto use merge workflow.
- If audioFiles has more than 1 item, app will auto merge audio tracks.
- Queue will create 1 job for that merged output.

Audio overlay note:
- `audioFiles` is for concat/merge of multiple audio files into one track.
- `audioFile2` is for a second audio layer that gets mixed on top of Audio 1.
- You can use both in the same job:
  - `audioFiles` => concat path
  - `audioFile2` => overlay/mix path

4C) CROSS-CLIP TRANSITIONS (FOR MERGE VIDEOS)
============================================================
When merging 2 or more video clips (mergeVideos = true), you can enable CapCut-style transitions between clips:

JSON Parameters:
- enableCrossTransitions: true / false
- crossTransitionType: string (Transition Name, e.g. "Whip Left", "Zoom", "Dissolve", "Fade (Blur)")
- crossTransitionDuration: double in seconds (e.g. 0.6, 0.8). Default: 0.6

Available 13 Transition Names (crossTransitionType):
- Dissolve          (Smooth cross-fade dissolve)
- Fade (Black)      (Fade to black & reveal next clip)
- Fade (White)      (Fade to white / flash reveal)
- Fade (Blur)       (Motion blur crossfade transition between clips)
- Whip Left         (Fast whip pan transition to the left)
- Whip Right        (Fast whip pan transition to the right)
- Whip Up           (Fast whip pan transition upwards)
- Whip Down         (Fast whip pan transition downwards)
- Zoom              (Unified dynamic zoom punch transition)
- Circle Crop       (Circular iris wipe transition)
- Radial Clock      (Clockwise radial wipe transition)
- Pixelize          (Digital pixelation transition)
- Light Leak Burn   (Filmic light leak & burn transition)
- HBlur             (Horizontal motion blur transition)

4E) TEXT OVERLAY API (FULL GUIDE & OPTIONS)
============================================================
Use these fields to add typewriter or static text overlay to the output video:

1) Core Text Parameters:
- textOverlay: string (e.g. "CÂU TRÍCH DẪN NGHỆ THUẬT") (Required to enable text overlay)
- textOverlayStyle: string (Font style selection - see supported values below)
- textOverlayColor: string (e.g. "white", "#FFFFFF", "yellow", "#FFD700") (Optional, default "white")
- textOverlayPosition: string ("Bottom Left", "Bottom Right", "Top Left", "Top Right", "Center", "Top", "Bottom")
- textAlign: string ("Left", "Center", "Right") (Optional, default "Center". Used for multi-line text alignment)
- textOverlayFontSize: integer (e.g. 28, 36, 48, 52) (Optional, default 28)
- addQuotes: boolean (true/false) (Optional, default true - automatically adds aesthetic quotes “ ”)

2) Static Mode & Custom Coordinates (New):
- disableTextScroll / staticText / noScroll: boolean (true/false)
  (Default false. When true, disables typewriter animation & keeps text static throughout video)
- textOverlayXPercent / textXPercent: double (0.0 to 1.0, e.g. 0.05 = left margin 5%)
- textOverlayYPercent / textYPercent: double (0.0 to 1.0, e.g. 0.85 = bottom margin 85%)

=== CROP / ZOOM ===
- cropEnabled: boolean (true/false)
- cropZoomPercent: double (1.0 - 200.0, ví dụ 15.5 tức là zoom vào 15.5%)
- cropAspectRatio: string ("1:1", "4:5", "16:9", "9:16")
- cropXPercent: double (0 - 100, ví dụ 50 là ở giữa chiều ngang)
- cropYPercent: double (0 - 100, ví dụ 50 là ở giữa chiều dọc)
- cropWidthPercent: double (10 - 100, ví dụ 80 là chiếm 80% chiều rộng video)
- cropHeightPercent: double (10 - 100, ví dụ 80 là chiếm 80% chiều cao video)

=== CAPTION SYNC (AI Whisper) ===
- enableCaptionSync: boolean (true/false) - Bật/tắt tự động tạo phụ đề theo lời audio
- captionSyncLanguage: string ("auto", "vi", "en", "ja", "ko", "zh") - Ngôn ngữ nhận dạng
- captionSyncModelSize: string ("Small", "Medium", "Large V3 Turbo") - Chọn model AI (càng lớn càng chính xác, default: Small)
- captionSyncAnimation: string ("None", "Spotify Scroll", "Pop", "Drift", "Glow", "Karaoke", "Typewriter", "Blur Reveal") - Chọn hiệu ứng (Mặc định tĩnh. Các tùy chọn: cuộn Spotify, nảy Pop & Bounce, trôi dạt Drift, toả sáng Glow, Karaoke Fade, Typewriter gõ chữ, Blur Reveal mờ ảo)
- captionSyncFontFamily: string (e.g. "Georgia", "Segoe UI", "Times New Roman", "Arial", "Thư Pháp") - Chọn Font chữ phụ đề
- captionSyncPosition: string ("Bottom Center", "Top Center", "Center", "Custom (X% Y%)") - Vị trí caption
- captionSyncXPercent: double (0-100) - Tọa độ X (dùng khi Position là Custom)
- captionSyncYPercent: double (0-100) - Tọa độ Y (dùng khi Position là Custom)
- captionSyncFontSize: integer (16-72, default 28) - Cỡ chữ caption
- captionSyncColor: string (e.g. "white", "yellow", "#FFD700") - Màu chữ caption

============================================================
4F) AUDIO 1 / AUDIO 2 API
============================================================
Use these fields when you want 2 audio layers in the same render:
- audioFile: Audio 1 primary track
- audioFile2: Audio 2 overlay track
- audioVolume: volume for Audio 1
- audio2Volume: volume for Audio 2
- secondaryAudioVolume: alias of audio2Volume

Behavior:
- If only audioFile exists, Titan uses it as the external audio track.
- If only audioFile2 exists, Titan uses it as the external audio track.
- If both exist, Titan mixes them together first, then continues with the normal external-audio pipeline.
- If audioFiles is also used, that is still the concat/merge mode for multiple audio sources.
- audioFile2 is not concat mode. It is a second layer that gets stacked onto Audio 1.

Recommended BAS JSON:
{
  "inputFile": "C:\\Users\\lemin\\Desktop\\input.mp4",
  "outputVideo": "C:\\Users\\lemin\\Desktop\\output\\audio_1_2_mix.mp4",
  "audioFile": "C:\\Users\\lemin\\Desktop\\music_1.mp3",
  "audioFile2": "C:\\Users\\lemin\\Desktop\\music_2.mp3",
  "audioVolume": 1.0,
  "audio2Volume": 0.8,
  "externalAudioSpeed": 1.0
}

If you want a single audio track made from many files:
- use audioFiles + mergeAudio
- do not use audioFile2 for concat

If you want one audio track plus a second layer:
- use audioFile + audioFile2
- set audioVolume / audio2Volume separately
- BAS can still poll the same statusUrl and done/jobSuccess fields as normal

4E) TEXT OVERLAY API
============================================================
Use these fields to add animated typewriter or static text to the output video:
- textOverlay: string (e.g. "CÂU TRÍCH DẪN NGHỆ THUẬT") (Required to enable text overlay)
- textOverlayStyle: string (Font style selection - see supported values below)
- textOverlayColor: string (e.g. "white", "#FFFFFF", "yellow", "#FFD700") (Optional, default "white")
- textOverlayPosition: string (Position preset: "Center", "Top", "Bottom", "Top Left", "Top Right", "Bottom Left", "Bottom Right")

- textOverlayFontSize: integer (e.g. 28, 36, 48, 52) (Optional, default 28)

Positioning & Static Mode (Easy & Flexible):
- disableTextScroll / staticText / noScroll: boolean (true/false) (Default false. When true, disables typewriter animation & keeps text static throughout video)
- textOverlayXPercent / textXPercent / textX: double (e.g. 10 or 0.10 = 10% from left, 50 = center X)

  * Cách nhập cực kỳ dễ dùng:

    - Chỉ cần truyền textX hoặc textY là hệ thống tự động nhận tọa độ ngay (tự động đè lên vị trí mặc định)!

9) SOUNDBAR - AUDIO VISUALIZER (enableSoundBar)
============================================================
Adds an audio-reactive bar / ring / waveform layer over the video. The bars are
rendered ONCE as a transparent PNG loop and then composited with FFmpeg overlay=,
so the soundbar COMPOSES with every other effect (overlay, watermark, brand logo,
template, upscale). You never have to choose between soundbar and other effects.

Enable with:
- enableSoundBar: true to render the soundbar layer (default false)

Style / look:
- soundBarStyle: one of the 12 canonical ids (see GET /api/soundbar/presets)
- soundBarPalette: palette id, default "ncs-cyan"
- soundBarOpacity: 0.05 - 1.0 (default 1.0)
- soundBarSensitivity: 0.0 - 3.0 (default 1.0). Higher = taller, more reactive bars.
- soundBarSmoothing: 0.0 - 1.0 (default 1.0). Higher = calmer / lazier motion.
- soundBarBarCount: 8 - 256 (default 64). Number of bars / columns / spokes.
- soundBarRoundness: 0.0 - 1.0 (default 1.0). 0 = flat hard-cap bars,
  1 = fully rounded pill caps.
- soundBarGlowIntensity: 0.0 - 3.0 (default 1.0). Multiplier on the additive glow.
- soundBarLoopSeconds: 1.0 - 6.0 (default 5.0). Length of the generated loop.
  The loop is repeated to cover the whole video.

!!! TWO DIFFERENT RANGES - API vs UI SLIDER !!!
The API range and the desktop slider range are NOT always the same number, so
both are listed here. Send the API range; the slider range is only what the app
happens to expose in the Soundbar panel.

  field                 API range (send this)      UI slider range
  --------------------  -----------------------   ------------------
  soundBarOpacity       0.05 - 1.0                 0.1 - 1.0
  soundBarSensitivity   0.0  - 3.0                 0.0 - 3.0
  soundBarSmoothing     0.0  - 1.0                 0.0 - 1.0
  soundBarBarCount      8    - 256                 8 - 256
  soundBarRingCount     1    - 8                   (no slider; API only)
  soundBarLoopSeconds   1.0  - 6.0                 (no slider; API only)
  soundBarRoundness     0.0  - 1.0                 (no slider; API only)
  soundBarGlowIntensity 0.0  - 3.0                 (no slider; API only)

Out-of-range values are CLAMPED, never rejected. A value outside the API range
is therefore accepted and quietly pinned to the nearest end - it does not error,
and it does not do anything you did not ask for either.

!!! WHY THESE RANGES - THEY ARE THE REAL ONES !!!
Every API range above is exactly the range the renderer consumes. Sending more
than that buys nothing, because the extra numbers all collapse onto the same
clamped result:

- soundBarSmoothing 0.0 - 1.0
  The renderer clamps to 0.0-1.0 and derives a one-pole filter coefficient
  k = 1 - 0.85 * smoothing. So 0.0 = raw bands (no filter at all), 1.0 = the
  calmest motion that exists (k = 0.15), and EVERY value above 1.0 produced the
  identical k = 0.15. An older build of this guide advertised 0.2-3.0 here,
  which meant roughly the top 58 % of the documented range was a dead zone.

- soundBarSensitivity 0.0 - 3.0
  The renderer clamps to 0.0-3.0, so anything above 3.0 is identical to 3.0.

- soundBarRingCount 1 - 8, and only two styles read it
  dual-rings    clamps to 2 - 6  (so 1 becomes 2, 7-8 become 6)
  ripple-rings  clamps to 1 - 8
  all 10 other styles IGNORE the field entirely - sending 9 changes nothing.
  Request 9 rings on dual-rings and you get 6, with no warning. Pick the style
  first, then pick a ring count inside that style's own range.

- soundBarLoopSeconds 1.0 - 6.0
  The render path runs the generator at a fixed 30 fps and the generator emits
  at most 180 frames, so 6.0 s is a hard ceiling. Anything longer was silently
  truncated to 6.0 s. Ask for longer loops by rendering a shorter video.

Position / size (percent of the output frame):
- soundBarXPercent: 0.0 - 1.0 (default 0.50). Anchor X. Accepts 0-100 too.
- soundBarYPercent: 0.0 - 1.0 (default 0.82). Anchor Y. Accepts 0-100 too.
- soundBarWidthPercent: 0.02 - 1.0 (default 0.62)
- soundBarHeightPercent: 0.02 - 1.0 (default 0.26)

Audio source:
- soundBarAudioSource: "auto" (default) | "external" | "video"
  auto     = prefer the external audio track, fall back to the video's own audio
  external = only the external audio track
  video    = only the source video's own audio track

Analysis tuning:
- soundBarRingCount: 1 - 8 (default 2). Only read by dual-rings (2-6) and
  ripple-rings (1-8). See the per-style note above.

Canonical soundBarStyle values:
- neon-bars          (Neon Bars, bottom-anchored)
- mirror-spectrum   (Center Mirror Spectrum)
- pill-bars         (Pill Bar Row)
- dense-columns     (Dense Thin Columns)
- dot-matrix        (Dot Matrix Grid)
- radial-ring       (Radial Spectrum Ring)
- dual-rings        (Dual Counter Rings)
- ripple-rings      (Ripple Pulse Rings)
- spoke-lines       (Radial Spoke Lines)
- wave-ribbon       (Waveform Ribbon)
- center-column     (Center Sound Column)
- peak-stars        (Peak Star Field)

Notes:
- Every field is optional. A bare "enableSoundBar": true already renders correctly.
- Out-of-range values are clamped, not rejected. An unknown style id falls back to
  "neon-bars"; an unknown audio source falls back to "auto".
- Re-rendering with UNCHANGED soundbar settings is fast: the PNG loop is cached
  on disk and reused instead of being generated again (~4 s saved). The cache is
  bounded at one entry per style, so changing any style or palette setting and
  then changing it back will regenerate that loop.
- If the audio cannot be analysed, the soundbar layer is SKIPPED and the video
  still renders. A soundbar failure never aborts a job.
- Aliases: soundBarStyle -> soundbarStyle, soundBarPalette -> soundbarPalette,
  soundBarAudioSource -> soundbarAudioSource, enableSoundBar -> soundBar / soundbar.

!!! PERCENT FIELD WARNING - READ BEFORE SENDING X / Y / WIDTH / HEIGHT !!!
The four position/size fields are:
  soundBarXPercent, soundBarYPercent, soundBarWidthPercent, soundBarHeightPercent

They accept TWO notations, and the switch happens at exactly 1.0:
  - any value ABOVE 1.0 is read as a PERCENTAGE and divided by 100
  - any value at or below 1.0 is read as a FRACTION and used as-is

Consequence: 1.0 means 100 %, NOT 1 %. It is the single worst value you can send.
  "soundBarYPercent": 1     -> means 100 %  (soundbar pinned to the frame BOTTOM)
  "soundBarYPercent": 1.0   -> means 100 %  (same thing)
  "soundBarYPercent": 0.01  -> means 1 %    (near the very top of the frame)
There is no way to express "1 %" with a value of 1. Send 0.01 instead.

Safe values - use one of these two forms and nothing else:
  FORM A (recommended, percent):  1.0 - 100.0
                                    e.g. 50.0 = 50 %, 82.0 = 82 %, 100.0 = 100 %
                                    NOTE: the value 1.0 is EXCLUDED from this range
                                    because it is indistinguishable from the
                                    fraction 1.0 and resolves to 100 %.
  FORM B (fraction):               0.01 - 0.99
                                    e.g. 0.50 = 50 %, 0.82 = 82 %
  Anything you send below 0.01 is clamped up to the field minimum, and anything
  above 100.0 is clamped down to 100.0. The four fields have their own minimums:
  X and Y allow 0.0 - 1.0 (0 % - 100 %); WIDTH and HEIGHT clamp to 0.02 - 1.0.

This notation is applied on the job as submitted and is never re-normalised later,
so double-check your computed percentages before posting.

10) GET /api/soundbar/presets
============================================================
Read-only discovery endpoint. Returns every soundbar style and every colour
palette so BAS can build a picker without hard-coding ids. No body required.

Method: GET (any other method returns 405)
Path:   /api/soundbar/presets

Response fields:
- success: true
- message: "Soundbar visualizer styles and palettes"
- soundBarStyles:   array of style entries (12 today), in menu order
- soundBarPalettes: array of palette entries

The two lists are SEPARATE arrays, not one flat list. Older builds returned a single
"soundBarPresets" array with the styles first and the palettes after, with no marker
at the boundary - a client had to probe every element for a "styleId" member just to
tell the two shapes apart. Read soundBarStyles and soundBarPalettes directly.

Style entry (every member is always present):
- styleId:          stable id, e.g. "neon-bars"
- name:             display name
- description:      one-line description of the style
- usesFft:          true when the style needs the FFT band data
- usesWaveform:     true when the style needs per-column min/max waveform data
- usesOnset:        true when the style reacts to onset (beat) detection
- usesRms:          true when the style uses overall RMS loudness
- defaultBarCount:  suggested bar count for this style

Palette entry:
- id:           stable id, e.g. "ncs-cyan"
- name:         display name
- vibe:         short mood descriptor
- genres:       comma-separated music genres the palette suits
- stops:        colour ramp, array of { offset: 0.0-1.0, hex: "#AARRGGBB" }
- core:         primary bar colour
- glow:         additive glow colour
- bgTint:       faint background tint used for the preview plate
- accent:       highlight / peak colour
- glowStrength: glow multiplier for this palette

11) TROUBLESHOOT
============================================================
- 503 Host mode is OFF:
  Turn HOST button ON.

- 429 Host is busy:
  Wait then retry.

- 404 jobId not found:
  Wrong jobId. Use jobId/statusUrl from add/render response.

- Merge fails:
  Ensure input files exist and are readable.
  Try same codec/container inputs for fastest concat.

- Fade not applied:
  Ensure request has:
  "enableFade": true
  "fadeInSeconds": number
  "fadeOutSeconds": number
  and check these values in API response.

- Soundbar missing from the output:
  Check the app log for a "[SOUNDBAR]" line. If it says "Audio analysis
  unavailable" the source had no decodable audio; add an audioFile or set
  soundBarAudioSource to "external". If it says "Overlay generation failed"
  the PNG loop could not be written; retry, and check free disk space in the
  system temp folder.

- Soundbar sits at the very edge of the frame:
  You almost certainly sent 1 meaning 1 %. It means 100 %. See the PERCENT FIELD
  WARNING in section 9 - send 0.01 for 1 %, or 1.0-100.0 for whole percentages.

- Soundbar renders as plain bars no matter what you asked for:
  The style id was not recognised, so it fell back to "neon-bars". Call
  GET /api/soundbar/presets and copy a styleId verbatim from soundBarStyles.

- Whip Left         (Fast whip pan transition to the left)
- Whip Right        (Fast whip pan transition to the right)
- Whip Up           (Fast whip pan transition upwards)
- Whip Down         (Fast whip pan transition downwards)
- Zoom              (Unified dynamic zoom punch transition)
- Circle Crop       (Circular iris wipe transition)
- Radial Clock      (Clockwise radial wipe transition)
- Pixelize          (Digital pixelation transition)
- Light Leak Burn   (Filmic light leak & burn transition)
