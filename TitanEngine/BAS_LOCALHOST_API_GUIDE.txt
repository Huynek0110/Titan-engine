============================================================
0) QUICK START
============================================================
- Open app, click HOST button -> HOST: ON
- Base URL: http://localhost:5555
- Recommended BAS flow:
  1) POST /api/queue/add
  2) POST /api/queue/start
  3) GET /api/render/status?jobId=...

Completion rule in BAS:
- done == true
- then check jobSuccess == true

Audio overlay rule:
- `audioFile` = Audio 1
- `audioFile2` = Audio 2
- `audioVolume` controls Audio 1 volume
- `audio2Volume` or `secondaryAudioVolume` controls Audio 2 volume
- If both `audioFile` and `audioFile2` exist, Titan mixes them together before render
- If only `audioFile2` exists, Titan uses it as the external audio track

============================================================
1) UI MERGE VIDEOS / IMAGES (MANUAL APP USAGE)
============================================================
If you want many sources -> 1 output file in UI:
1) Select multiple videos/images
2) Tick: "Merge Videos Into One Output (Concat)"
3) (Optional) Select multiple audio files + tick "Merge Audio Tracks Into One Output (Concat)"
4) (Optional) Select a Template in FX Studio (CapCut style preset)
5) Set FX/Color/Upscale/etc as normal
6) Click ADD TO QUEUE

Result:
- Only 1 queue item is created
- Render output is 1 merged video

============================================================
2) API ENDPOINTS
============================================================
[A] POST /api/queue/add
- Add job to queue only (no render yet)

[B] POST /api/queue/start
- Start all pending queue jobs

[C] GET /api/render/status?jobId=DE64988F
- Poll current job state
- Supports jobId string or queueId number

[D] POST /api/render
- Add + render immediately in background (async)

[E] POST /api/render/async
- Same as /api/render async behavior

[F] POST /api/render/wait
- Blocking mode (wait until done)

============================================================
3) MERGE VIDEOS + MERGE AUDIO VIA API
============================================================
Use these fields:
- inputFiles: array of video paths
- inputFiles can also include image paths (.png/.jpg/.jpeg)
- mergeVideos: true
- audioFiles: array of audio paths (optional)
- mergeAudio: true (optional, auto true when audioFiles > 1)
- outputVideo: final output path
- templateName: optional preset name

Example (merge 2 videos -> 1 output):
POST http://localhost:5555/api/queue/add
{
  "inputFiles": [
    "C:\\Users\\lemin\\Desktop\\clip1.mp4",
    "C:\\Users\\lemin\\Desktop\\clip2.mp4"
  ],
  "audioFiles": [
    "C:\\Users\\lemin\\Desktop\\music1.mp3",
    "C:\\Users\\lemin\\Desktop\\music2.mp3"
  ],
  "mergeVideos": true,
  "mergeAudio": true,
  "templateName": "Smooth Zoom In",
  "outputVideo": "C:\\Users\\lemin\\Desktop\\output\\merged_final.mp4",
  "colorGrading": "Warm",
  "fxEffect": "None"
}

Important:
- If inputFiles has more than 1 item, app will auto use merge workflow.
- If audioFiles has more than 1 item, app will auto merge audio tracks.
- Queue will create 1 job for that merged output.

Audio overlay note:
- `audioFiles` is for concat/merge of multiple audio files into one track.
- `audioFile2` is for a second audio layer that gets mixed on top of Audio 1.
- You can use both in the same job:
  - `audioFiles` => concat path
  - `audioFile2` => overlay/mix path

4C) CROSS-CLIP TRANSITIONS (FOR MERGE VIDEOS)
============================================================
When merging 2 or more video clips (mergeVideos = true), you can enable CapCut-style transitions between clips:

JSON Parameters:

- Fade (Blur)       (Motion blur crossfade transition between clips)
- Whip Left         (Fast whip pan transition to the left)
- Whip Right        (Fast whip pan transition to the right)
- Whip Up           (Fast whip pan transition upwards)
- Whip Down         (Fast whip pan transition downwards)
- Zoom              (Unified dynamic zoom punch transition)
- Circle Crop       (Circular iris wipe transition)
- Radial Clock      (Clockwise radial wipe transition)
- Pixelize          (Digital pixelation transition)
- Light Leak Burn   (Filmic light leak & burn transition)

4E) TEXT OVERLAY API (FULL GUIDE & OPTIONS)
============================================================
Use these fields to add typewriter or static text overlay to the output video:

1) Core Text Parameters:
- textOverlay: string (e.g. "CÂU TRÍCH DẪN NGHỆ THUẬT") (Required to enable text overlay)
- textOverlayStyle: string (Font style selection - see supported values below)
- textOverlayColor: string (e.g. "white", "#FFFFFF", "yellow", "#FFD700") (Optional, default "white")
- textOverlayPosition: string ("Bottom Left", "Bottom Right", "Top Left", "Top Right", "Center", "Top", "Bottom")
- textAlign: string ("Left", "Center", "Right") (Optional, default "Center". Used for multi-line text alignment)
- textOverlayFontSize: integer (e.g. 28, 36, 48, 52) (Optional, default 28)
- addQuotes: boolean (true/false) (Optional, default true - automatically adds aesthetic quotes “ ”)

2) Static Mode & Custom Coordinates (New):
- disableTextScroll / staticText / noScroll: boolean (true/false)
  (Default false. When true, disables typewriter animation & keeps text static throughout video)
- textOverlayXPercent / textXPercent: double (0.0 to 1.0, e.g. 0.05 = left margin 5%)
- textOverlayYPercent / textYPercent: double (0.0 to 1.0, e.g. 0.85 = bottom margin 85%)

=== CROP / ZOOM ===
- cropEnabled: boolean (true/false)
- cropZoomPercent: double (1.0 - 200.0, ví dụ 15.5 tức là zoom vào 15.5%)
- cropAspectRatio: string ("1:1", "4:5", "16:9", "9:16")
- cropXPercent: double (0 - 100, ví dụ 50 là ở giữa chiều ngang)
- cropYPercent: double (0 - 100, ví dụ 50 là ở giữa chiều dọc)
- cropWidthPercent: double (10 - 100, ví dụ 80 là chiếm 80% chiều rộng video)
- cropHeightPercent: double (10 - 100, ví dụ 80 là chiếm 80% chiều cao video)

=== CAPTION SYNC (AI Whisper) ===
- enableCaptionSync: boolean (true/false) - Bật/tắt tự động tạo phụ đề theo lời audio
- captionSyncLanguage: string ("auto", "vi", "en", "ja", "ko", "zh") - Ngôn ngữ nhận dạng
- captionSyncModelSize: string ("Small", "Medium", "Large V3 Turbo") - Chọn model AI (càng lớn càng chính xác, default: Small)
- captionSyncAnimation: string ("None", "Spotify Scroll", "Pop", "Drift", "Glow", "Karaoke", "Typewriter", "Blur Reveal") - Chọn hiệu ứng (Mặc định tĩnh. Các tùy chọn: cuộn Spotify, nảy Pop & Bounce, trôi dạt Drift, toả sáng Glow, Karaoke Fade, Typewriter gõ chữ, Blur Reveal mờ ảo)
- captionSyncFontFamily: string (e.g. "Georgia", "Segoe UI", "Times New Roman", "Arial", "Thư Pháp") - Chọn Font chữ phụ đề
- captionSyncPosition: string ("Bottom Center", "Top Center", "Center", "Custom (X% Y%)") - Vị trí caption
- captionSyncXPercent: double (0-100) - Tọa độ X (dùng khi Position là Custom)
- captionSyncYPercent: double (0-100) - Tọa độ Y (dùng khi Position là Custom)
- captionSyncFontSize: integer (16-72, default 28) - Cỡ chữ caption
- captionSyncColor: string (e.g. "white", "yellow", "#FFD700") - Màu chữ caption

============================================================
4F) AUDIO 1 / AUDIO 2 API
============================================================
Use these fields when you want 2 audio layers in the same render:
- audioFile: Audio 1 primary track
- audioFile2: Audio 2 overlay track
- audioVolume: volume for Audio 1
- audio2Volume: volume for Audio 2
- secondaryAudioVolume: alias of audio2Volume

Behavior:
- If only audioFile exists, Titan uses it as the external audio track.
- If only audioFile2 exists, Titan uses it as the external audio track.
- If both exist, Titan mixes them together first, then continues with the normal external-audio pipeline.
- If audioFiles is also used, that is still the concat/merge mode for multiple audio sources.
- audioFile2 is not concat mode. It is a second layer that gets stacked onto Audio 1.

Recommended BAS JSON:
{
  "inputFile": "C:\\Users\\lemin\\Desktop\\input.mp4",
  "outputVideo": "C:\\Users\\lemin\\Desktop\\output\\audio_1_2_mix.mp4",
  "audioFile": "C:\\Users\\lemin\\Desktop\\music_1.mp3",
  "audioFile2": "C:\\Users\\lemin\\Desktop\\music_2.mp3",
  "audioVolume": 1.0,
  "audio2Volume": 0.8,
  "externalAudioSpeed": 1.0
}

If you want a single audio track made from many files:
- use audioFiles + mergeAudio
- do not use audioFile2 for concat

If you want one audio track plus a second layer:
- use audioFile + audioFile2
- set audioVolume / audio2Volume separately
- BAS can still poll the same statusUrl and done/jobSuccess fields as normal

4E) TEXT OVERLAY API
============================================================
Use these fields to add animated typewriter or static text to the output video:
- textOverlay: string (e.g. "CÂU TRÍCH DẪN NGHỆ THUẬT") (Required to enable text overlay)
- textOverlayStyle: string (Font style selection - see supported values below)
- textOverlayColor: string (e.g. "white", "#FFFFFF", "yellow", "#FFD700") (Optional, default "white")
- textOverlayPosition: string (Position preset: "Center", "Top", "Bottom", "Top Left", "Top Right", "Bottom Left", "Bottom Right")
- textAlign: string ("Left", "Center", "Right") (Optional, default "Center". Used for multi-line text alignment)
- textOverlayFontSize: integer (e.g. 28, 36, 48, 52) (Optional, default 28)
- addQuotes: boolean (true/false) (Optional, default true - automatically adds aesthetic quotes “ ”)

Positioning & Static Mode (Easy & Flexible):
- disableTextScroll / staticText / noScroll: boolean (true/false) (Default false. When true, disables typewriter animation & keeps text static throughout video)
- textOverlayXPercent / textXPercent / textX: double (e.g. 10 or 0.10 = 10% from left, 50 = center X)
- textOverlayYPercent / textYPercent / textY: double (e.g. 85 or 0.85 = 85% from top, near bottom)
  * Cách nhập cực kỳ dễ dùng:
    - Nhập dạng số nguyên 0 -> 100 (ví dụ: textX: 10 nghĩa là 10% lề trái, textY: 85 nghĩa là 85% dưới đáy).
    - Hoặc nhập dạng thập phân 0.0 -> 1.0 (ví dụ: textX: 0.10, textY: 0.85).
    - Chỉ cần truyền textX hoặc textY là hệ thống tự động nhận tọa độ ngay (tự động đè lên vị trí mặc định)!

Neon Glow Styling (New):
- enableTextGlow / textGlow: boolean (true/false) (Default false. Enables vibrant neon aura glow behind text)
- textGlowColor / glowColor: string ("Cyan Neon", "Magenta Neon", "Gold Neon", "Emerald Neon", "Electric Purple", "Hot Pink", "Red Glow", "White Glow")

Supported textOverlayStyle values:
1) "Aesthetic Lyric (Georgia / Times Italic)" (or "Georgia" / "Lyric") [Default]
   - Classic cinematic serif style.
   - Auto-Detect Rule: If text contains Vietnamese diacritics, Titan automatically uses Times New Roman Italic (same classic serif look with 100% Vietnamese unicode support) to avoid broken glyphs.
2) "Modern Sans (Segoe UI Italic)" (or "Segoe UI" / "Segoe")

8) TROUBLESHOOT
============================================================
- 503 Host mode is OFF:
  Turn HOST button ON.

- 429 Host is busy:
  Wait then retry.

- 404 jobId not found:
  Wrong jobId. Use jobId/statusUrl from add/render response.

- Merge fails:
  Ensure input files exist and are readable.
  Try same codec/container inputs for fastest concat.

- Fade not applied:
  Ensure request has:
  "enableFade": true
  "fadeInSeconds": number
  "fadeOutSeconds": number
  and check these values in API response.
