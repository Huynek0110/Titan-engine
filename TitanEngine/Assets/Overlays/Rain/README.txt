Rain Overlay Assets
===================

Drop real rain overlay video files into this folder. The render engine is asset-only for Rain Overlay and will fail fast if these files are missing.

Preferred filenames
-------------------
- rain_heavy_black_bg_01.mp4
- rain_cinematic_black_bg_01.mp4
- rain_window_drops_01.mp4

Suggested source pages
----------------------
- Pexels heavy black background rain:
  https://www.pexels.com/video/heavy-rain-falling-on-black-background-36344044/
- Pexels window drops:
  https://www.pexels.com/video/rain-drops-streaming-down-a-window-pane-35184743/
- Pixabay cinematic rain overlay option:
  https://pixabay.com/videos/rain-water-raining-nature-overlay-214990/

License notes
-------------
- Pexels: https://www.pexels.com/license/
- Pixabay: https://pixabay.com/service/license-summary/

Notes
-----
- Do not replace missing rain assets with generated particles or procedural lines.
- After downloading, keep the filenames above so the app can auto-detect them.
- If you prefer a custom file path, pass it through the API field `rainOverlayAssetPath`.
